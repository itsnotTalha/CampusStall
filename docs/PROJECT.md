# UniHub

UniHub is a student marketplace with four primary areas:

1. Ready-Made Projects
   Students sell software, ML, IoT, electronics, design and other projects they own or are permitted to distribute.

2. Hire Talent
   Students offer development, design, tutoring, debugging, consulting and customization services.

3. Project Help
   Users request mentoring, debugging, project consultation, teammates or customization.

4. Digital Perks
   Legitimate student software discounts, licenses, resources and offers. No password/account sharing.

## Academic integrity

The platform supports learning, legitimate reuse, tutoring, mentoring, debugging and licensed project assets. It must not promote exam impersonation, plagiarism, credential sharing or submitting someone else's assessed work as one's own.

## Initial target users

University students, especially CSE/EEE/engineering students.

## Initial currency

BDT using the ৳ symbol.

## Design direction

Modern SaaS marketplace.
Inspired conceptually by Linear/Vercel/Airbnb style cleanliness without copying them.
Clean typography, large cards, subtle borders, restrained shadows, generous whitespace.
Excellent dark mode later.
Responsive from mobile to desktop.
