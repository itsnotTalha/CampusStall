# Repository Instructions

- Read `AGENTS.md` before every task.
- Read `docs/PROJECT.md` only when product context is needed.
- Inspect only files relevant to the current task; avoid broad unnecessary repo scans.
- Reuse existing components before creating new ones.
- Do not rewrite unrelated files.
- Keep components reasonably small and reusable.
- Prefer Server Components unless client-side interactivity is actually required.
- Use TypeScript strictly; avoid `any`.
- Keep mock/data definitions separate from presentational components.
- Never hardcode secrets.
- Never expose server credentials to the browser.
- Keep the project Vercel-compatible.
- Preserve existing functionality unless the task explicitly changes it.
- Run targeted lint/type checks after modifications.
- Do not run expensive/full checks unless necessary.
- Do not create unnecessary documentation.
- Do not produce long explanations after tasks.
- Final response should contain only:
  1. summary
  2. files changed
  3. commands/tests run
  4. any blocker
